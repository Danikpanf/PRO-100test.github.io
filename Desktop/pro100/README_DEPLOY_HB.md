# Деплой на HB.by (статический сайт)

Этот проект — статический сайт (HTML + картинки). Никакой сборки не требуется.

## Что заливать на хостинг

Содержимое папки `Desktop/pro100/`:

- `index.html`
- `img/` (все картинки)
- `robots.txt`
- `sitemap.xml`
- `favicon.svg`
- `site.webmanifest`
- `.htaccess` (если на тарифе используется Apache и разрешён `.htaccess`)

## Куда заливать

На виртуальном хостинге HB.by обычно корневая папка сайта называется **`public_html`** или **`httpdocs`**.
Файлы сайта должны лежать внутри неё, а главный файл должен называться **`index.html`**.

Источник: документация HB.by про размещение сайта на хостинге (упоминаются `public_html` / `httpdocs`):  
`https://hb.by/kb/kak-razmestit-sayt-wordpress-na-hostinge` (подходит и для статических сайтов).

## Быстрая проверка перед заливкой

Открой сайт локально через простой сервер:

```bash
python -m http.server 5173
```

И проверь в браузере: `http://127.0.0.1:5173/`

## Важно про имена картинок

На хостинге могут быть проблемы с именами файлов на кириллице/в “битой” кодировке.
Если какие-то фото не грузятся после деплоя — лучше переименовать файлы в `img/` в латиницу и обновить ссылки в `index.html`.
